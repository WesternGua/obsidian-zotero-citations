# Zotero Citations

> 在 Obsidian 中管理 Zotero 引用，支持脚注/尾注模式、Word 风格显示，并一键导出为保留 Zotero 动态引文域的 Word 文档。

[English](./README.md)

---

## 功能亮点

- **插入引用** — 调用 Zotero 原生引文选择器，支持页码/段落定位符
- **脚注 / 尾注 / 文内引用** — 自由切换脚注模式（`^[引用文本]`）、尾注模式（`[^1]` + 文末定义）和文内模式（正文作者-年份引用）
- **Word 风格显示** — 编辑器中脚注标记以上标数字呈现，悬停可查看完整引用并编辑定位符
- **仅使用 Zotero 样式** — 只显示并使用 Zotero 当前已经安装的 CSL 样式，不提供内置或近似回退样式
- **保持 CSL 输出一致** — 同步 Zotero 的样式文件和语言规则，并支持父子样式、参考文献排序和组合引文
- **参考书目** — 自动汇总当前文档所有引用，生成格式化参考文献列表
- **复制时携带脚注** — 普通复制粘贴即可转移完整脚注内容，处理编号冲突并保留 Zotero 元数据
- **导出为 Word** — 通过 Pandoc 和内置 Better BibTeX Lua 过滤器生成 `.docx`；脚注、尾注和文内引用均转换为可由 Zotero 刷新和切换样式的动态引文域
- **中英双语界面** — 设置中一键切换

## 前置要求

| 组件 | 说明 |
|------|------|
| Obsidian 桌面版 1.5.7+ | 插件仅支持桌面端（`isDesktopOnly: true`） |
| [Zotero](https://www.zotero.org/) | 文献管理器，需保持运行 |
| [Better BibTeX](https://github.com/retorquere/zotero-better-bibtex/releases) | Zotero 插件，提供 API 通信 |
| [Pandoc](https://pandoc.org/installing.html)（可选） | 仅导出 Word 时需要 |

## 安装

1. 从 GitHub Releases 页面下载以下文件：
   - `main.js` — 插件主程序
   - `manifest.json` — 插件清单
   - `styles.css` — 插件样式
2. 将以上文件放入 vault 的 `.obsidian/plugins/zotero-citations/` 目录（如目录不存在则手动创建）
3. 在 Obsidian 设置 → 第三方插件中启用 **Zotero Citations**
4. 确保 Zotero 已打开且 Better BibTeX 已安装
5. （如需导出 Word）安装 Pandoc 并确保其在系统 PATH 中

## 披露说明

- **网络访问**：插件会通过 `127.0.0.1` 本地回环地址与 Zotero / Better BibTeX 通信，不会连接插件自建服务器。
- **外部文件与可执行程序访问**：插件会读取本机 Zotero 样式目录；在部分回退场景下可能复制并读取本机 Zotero 数据库到系统临时目录；导出 Word 时会调用本地 `pandoc`；数据库回退解析时可能调用本地 `sqlite3`；在 macOS 上，为了从 Zotero 选择器返回 Obsidian，插件可能调用系统 `osascript`。
- **本地数据存储**：插件会在 Obsidian 的插件数据中保存设置项和引用缓存。
- **账户 / 付费 / 广告 / 遥测**：插件不要求登录账户，不含广告，不含内购，也不主动收集遥测数据。
- **源码状态**：插件源码已公开在 GitHub 仓库中，并以 MIT 许可证发布：<https://github.com/WesternGua/obsidian-zotero-citations>

## 快速上手

### 1. 插入引用

在命令面板中搜索“插入引用”，或点击标题栏中的插入引用图标。

插件调用 Zotero 原生引文选择器——在弹出窗口中搜索并选择条目，可填写页码等定位符，点击右上角 ✔ 确认插入。

引用插入后会按当前引用模式显示（脚注 / 尾注 / 文内）。

> **注意**：
> - 插件会在脚注正文开头写入 `<!-- zotero:ITEMKEY:locator -->` 形式的隐藏元数据，请勿手动删除，否则插件无法识别该引用。
> - 定稿后如需移除插件元数据，可执行“解除引用链接”（不可逆），插件会删除隐藏元数据并保留可见引用文本。

![insert-citation-preview](assets/screenshots/insert-citation-preview.png)

### 2. 悬停编辑定位符

开启 Word 风格脚注显示后，鼠标悬停上标数字即可查看完整引用内容，并直接修改页码/段落定位符：

脚注预览中的定位数字直接带有小边框。点击数字后，在原位置选择定位类型并填写数值或范围。类型菜单的内容和顺序与 Zotero 一致。按 Enter 保存，Esc 取消。没有显示定位的文献提供紧凑的添加或编辑入口，悬停入口可查看对应文献标题。组合引文中的每条文献和重复条目均可分别编辑。清空数值只会移除对应文献的定位。保存时保持当前光标和阅读位置，不会跳转到文末脚注。

![悬停预览与定位符编辑](assets/screenshots/zh-hover-preview.png)

### 3. 切换引用样式

执行“文档首选项”打开文档首选项窗口。插件会动态读取 Zotero 中已安装的所有 CSL 样式，以可搜索列表形式展示；选择所需样式后，可同时切换脚注/尾注/文内模式，并一键应用到当前文档的所有引用：

![文档首选项](assets/screenshots/zh-preferences.png)

### 4. 插入参考书目

执行“插入参考书目”，插件会在光标位置生成当前文档所有引用的参考文献列表。导出 Word 时，该受管理的参考书目会转换为 Zotero 动态参考文献域。

![insert-bibliography-preview](assets/screenshots/insert-bibliography-preview.png)

### 5. 导出为 Word

1. 确保 Zotero 正在运行且 Better BibTeX 已启用
2. 在命令面板中执行“检测 Pandoc 是否可用”，确认 Pandoc 正常工作
3. 执行“导出为 Word (.docx)”

插件只会在系统临时目录中把受管理引用转换为 Pandoc `[@citationKey]` 语法，不会改写原 Markdown 笔记。导出的脚注、尾注和文内引用都会包含 `ZOTERO_ITEM CSL_CITATION` 动态域。DOCX 会写入 Zotero 已安装 CSL 样式的准确 URI，包括不使用 Zotero 官方样式域名的自定义样式，同时写入 Zotero 语言地区和注释类型。Better BibTeX 无法解析样式或 citation key 时，导出会显示错误并停止，不会生成包含纯文本 citation key 的 Word 文档。打开 Word 文档后可直接点击 Zotero“Refresh”，也可在“Document Preferences”中改用其他 Zotero 样式。

正文为宋体小四、1.5 倍行距、两端对齐、首行缩进两字符，标题为黑体。

![export-to-word-preview](assets/screenshots/export-to-word-preview.png)

## 0.3.0 的刷新、注释与异常处理

在生成的引文后直接填写注释即可。不可见的 `<!-- /zotero-citation -->` 标记区分引文与自写内容，刷新、修改定位和 Word 导出都会保留自写内容。旧脚注只有在能够确认引文边界时才自动迁移，无法确认的脚注保留原文。

双击正文脚注序号跳到脚注定义，双击定义序号返回上次跳转的正文位置。没有记录时返回第一处引用。

正常引用继续刷新，缺失条目或损坏元数据所在的整个组合保留原文。刷新结束后高亮第一条异常，并在右上角显示更新数量、异常列表、上一条、下一条和返回原位置按钮。模式互转保留组合中的全部文献及注释。多段脚注无法完整转入行内模式时保留原脚注并说明原因。

连接或 Better BibTeX CAYW 出错时直接报错，已删除插件内备用搜索界面。设置中的 Zotero 端口默认是 `23119`，Word 导出也使用相同端口。只有 Zotero/Better BibTeX 实际使用其他端口时才需要修改。

## 设置

### 复制粘贴时携带脚注

在源码模式或实时预览中，选中包含完整 `[^标签]` 标记的一段正文，照常使用 `Cmd+C` / `Cmd+V`。插件从当前编辑器收集对应定义，包括尚未保存的修改。正文插入光标位置或替换目标选区，新定义放在文末或插件管理的参考书目之前。目标已有同名但内容不同的脚注时，新正文标记与定义标签同时重命名。内容完全一致的现有定义可以复用，包括上次粘贴时已经重命名的定义。选区内已经包含的定义不会重复追加。

支持普通脚注、多行定义、重复引用和 Zotero 组合引文。原有格式、Zotero 条目键、定位信息及注释均保留，复制粘贴无需连接 Zotero，也不会自动重新格式化引用。一次撤销可以同时撤回正文和新增定义。剪贴板同时携带插件专用数据与包含完整定义的 Markdown 文本。剪贴板管理工具移除专用格式后，普通文本仍可导入。粘贴到其他应用的文本也包含对应定义。

本功能处理一个连续编辑器选区，不受当前引用模式和 Word 风格显示开关影响。阅读模式、剪切、多个同时选区、代码示例、不完整的定义，以及向脚注定义或代码块内部粘贴，继续使用原有行为。`^[内容]` 形式的内联脚注本身已携带内容，也继续使用原有复制行为。Windows 和 Linux 快捷键为 `Ctrl+C` / `Ctrl+V`，这两个平台尚未完成验证。

### 主要设置项

| 设置 | 说明 |
|------|------|
| 界面语言 | 中文 / English |
| 默认 CSL 样式 | 新插入引用使用的格式 |
| 引用格式模式 | 脚注 / 尾注 / 文内 |
| Word 风格脚注显示 | 上标数字 + 悬停预览 |
| 标题栏按钮 | 主开关 + 6 个子开关（插入引用、切换 Word 风格脚注显示、刷新所有引用、修改引用格式、解除引用链接、导出为 Word），可在设置中分别控制每个按钮的显隐 |
| Pandoc 路径 | 默认 `pandoc`，可填完整路径 |
| 额外 Pandoc 参数 | 如 `--reference-doc=template.docx` |
| 固定导出目录 | 不设则每次弹出选择框 |
| 默认导出目录 | 仅在开启固定导出目录时显示；留空则使用当前文档所在目录 |
